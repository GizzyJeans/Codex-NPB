## 這個翻正不構成證據

三個獨立的檢查都指向同一結論。

**一、統計上與 0 無法區分。** 同日候選共用同一套參數，不是獨立樣本，因此以「日」為單位計算：

| | 值 |
|---|---:|
| 各日 WATCH ROI | +16.2%、−88.0%、+4.0%、+3.6%、+70.0% |
| 平均日 ROI | +1.2% |
| 標準差 | 56.9% |
| 標準誤 | 25.4% |
| t | **+0.05** |
| 95% bootstrap CI | **[−48.8%, +43.5%]** |

n=5 的雙尾 5% 臨界值為 t=2.78，實際 t=0.05。信賴區間寬達 92 個百分點且跨越 0。

**二、扣掉單日就翻回負值。**

| 樣本 | 候選數 | ROI |
|---|---:|---:|
| 全部 | 33 | +5.8% |
| 僅前瞻市場 | 31 | **+2.0%** |
| 扣掉 08-30 | 26 | **−11.4%** |

+5.8% 的頭條數字有兩層灌水：兩個非前瞻市場貢獻 +1,310，而剩下的幾乎全部來自單一天。

**三、與 557 場回測牴觸。** 逐日前推的回測顯示模型在分差上僅勝過「猜聯盟平均」約 2%（t=2.67），總分則不顯著。五天的影子結果不足以推翻 557 場的走查結果。

08-26 那天 +16.2% 時已註明落在運氣範圍，隔日 −88.0% 證實了該判斷。今日 +70.0% 適用同一標準，不因方向有利而放寬。
